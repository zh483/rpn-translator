## 一、三条边界规则（已定稿，不要再改）

### 规则 1：全角数字 —— ⏳ 待你选 A/B

- **A**：保留文本框（满足"输入和编辑"），词法器用 ASCII 判断兜底（`c >= '0' && c <= '9'`，两处），输入层再加过滤。
- **B**：纯按钮键盘（计算器形态），输入天然受控，跳过这条；同时要改报告 2.1.2 与 图3-1。

> 现状：`Character.isDigit('１')` 返回 true → 走数字分支 → `Double.parseDouble("１")` 抛**未捕获** `NumberFormatException`，程序崩。它同时会放过阿拉伯数字 `٣`、印度数字 `३` 等所有 Unicode 数字。

### 规则 2：`1.2.3` / `1..2` —— 词法层不报错

- `1.2.3` → `NUM("1.2")@0` `NUM(".3")@3` `EOF@5`
- `1..2` → `NUM("1.")@0` `NUM(".2")@2` `EOF@4`

**理由**：`1.` 和 `.2` 都是合法数字（规则 `Digits . [Digits]` 与 `. Digits`），词法器的职责是"最长匹配切出合法记号"，切出两个 NUM 是正确的；"两个数字相邻"是**结构错误**，由 `Parser` 报 `[语法错误] …期望运算符或结束，实际读到数字`。

**连带责任**：`Parser` 必须真的能报这个错（Day 05 验收项）。

### 规则 3：括号不匹配归语法层

`(1+2` 词法层不报错：正常返回 `LPAREN NUM PLUS NUM EOF`，由 `Parser` 报"期望 ')'"。词法层不数括号。

## 二、写 TestRunner（40 分钟）

### 设计要求

- 主类 `TestRunner`，`main` 跑完全部用例
- 输出表格：`编号 | 输入 | 期望 | 实际 | PASS/FAIL`
- 结尾 `通过 x / 失败 y`；**有失败就 `System.exit(1)`**
- 辅助方法把 token 流渲染成固定格式再比较：

```
NUM(12)@0 PLUS(+)@1 NUM(3)@2 EOF@5
```

### 16 条用例

**合法组（10 条）**

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| L01 | `1` | `NUM(1)@0 EOF@1` |
| L02 | `12` | `NUM(12)@0 EOF@2` |
| L03 | `3.14` | `NUM(3.14)@0 EOF@4` |
| L04 | `.5` | `NUM(.5)@0 EOF@2` |
| L05 | `5.` | `NUM(5.)@0 EOF@2` |
| L06 | `1+2*3` | `NUM(1)@0 PLUS(+)@1 NUM(2)@2 STAR(*)@3 NUM(3)@4 EOF@5` |
| L07 | `(1+2)*3` | `LPAREN(()@0 NUM(1)@1 PLUS(+)@2 NUM(2)@3 RPAREN())@4 STAR(*)@5 NUM(3)@6 EOF@7` |
| L08 | `1 + 2` | `NUM(1)@0 PLUS(+)@2 NUM(2)@4 EOF@5` |
| L09 | `8/4%3` | `NUM(8)@0 SLASH(/)@1 NUM(4)@2 PERCENT(%)@3 NUM(3)@4 EOF@5` |
| L10 | （空串） | `EOF@0` |

**边界组（2 条，规则 2）**

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| B01 | `1.2.3` | `NUM(1.2)@0 NUM(.3)@3 EOF@5` |
| B02 | `1..2` | `NUM(1.)@0 NUM(.2)@2 EOF@4` |

**错误组（4 条）**

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| E01 | `1$a` | `[词法错误] 第 2 个字符` |
| E02 | `.` | `[词法错误] 第 1 个字符` |
| E03 | `12ab` | `[词法错误] 第 3 个字符` |
| E04 | `#` | `[词法错误] 第 1 个字符` |

> 若选 A（全角兜底），加第 17 条：`１+２` → `[词法错误] 第 1 个字符`。
> 位置一律 **1 基**。错误断言只比对"类别 + 第 n 个字符"，不比对整句消息。
