# Day 05 任务卡 · Parser：递归下降 + 综合属性

> **时间盒 60–90 分钟**。目标：把 token 流翻译成**后缀表达式字符串**。
> 一句话概括今天要做的事：**每个非终结符写一个方法，方法返回值就是它的后缀串**。
> 不写 AST、不做求值（Evaluator 是 Day 06）。

## 一、文法（已消左递归，对应 ADR-002）

```
E  → T E'
E' → + T E' | - T E' | ε
T  → F T'
T' → * F T' | / F T' | % F T' | ε
F  → ( E ) | num | - F
```

属性：**每个非终结符一个综合属性 `postfix`**，在 Java 里就是**方法返回值**。

对应到报告的 2.2.2 节（表2-4 属性文法与语义规则），实现时逐条对照即可。

## 二、拼接约定

- 后缀串以**空格分隔记号**，例如 `1 2 3 * +`
- `ε` 返回空串 `""`
- 一元负号输出专用记号 **`neg`**（对应 ADR-004，避免与二元减号混淆）
- 拼接顺序永远是：**左操作数串 + 右操作数串 + 运算符**

## 三、需要的方法（签名，实现你写）

```java
public class Parser {

    /** 入口：解析并返回后缀表达式。解析完必须消费掉 EOF。 */
    public String parse();          // 先调 expr()，再 expect(EOF)，否则报"多余的记号"

    private String expr();
    private String exprPrime();
    private String term();
    private String termPrime();
    private String factor();
}
```

内部状态建议（具体怎么存你定）：

- token 列表 + 当前索引（lookahead 一个记号就够，LL(1)）
- `check(TokenType)`：当前记号是不是指定类型
- `next()`：吃掉当前记号并前进
- `expect(TokenType)`：不是指定类型就抛 `CompileException(Kind.SYNTAX, 当前.pos(), "期望 X，实际读到 Y")`

## 五、几个具体提示（思路，不是代码）

1. **`exprPrime` 里看完运算符要 `next()` 再递归**，否则会无限循环在同一位置。
2. **`factor` 遇到 `(` 时**：`next()` 掉左括号 → 调 `expr()` → `expect(RPAREN)` → 返回中间那个串（括号本身不产生记号）。
3. **一元负号**：`factor` 里遇到 `-` 时，先 `next()`，再递归 `factor()`，返回 `子串 + " neg"`（注意顺序：后缀式里运算符在后面）。
4. **别用成员变量累加后缀串**——属性就是返回值，返回值就是属性。用成员变量就变成了"隐式全局状态"，一旦递归顺序变化就出错。
5. **EOF 也是一个 token**，位置等于原串长度，用它报"意外结束"的错误位置很准。
